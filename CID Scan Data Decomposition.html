Read TP and SPL workbooks, then choose an analysis.
Enter the residual thickness for each TP sheet in millimeters. The analysis uses the 2 mm region centered on the entered TP notch position (−1 mm to +1 mm).
TP analysis combines point-wise thickness correlation, discretized functional PCA, pairwise waveform distance, monotonic feature analysis, and grouped PLSR cross-validation. Cross-validation holds out an entire TP sheet so multiple scan lines from the same specimen cannot leak into both train and test folds.
Because no notch-free CID exists, the background basis B is learned from off-notch windows of the actual SPL scans. The known notch position defines the 2 mm ROI; cross-correlation is used only for fine spatial alignment. The local decomposition is y = Bc + Ka + error, with ridge regularization on the kernel coefficients. Thickness is reported from PLSR, linear-kernel ridge regression, RBF-GPR, and nearest-reference matching.
